# Property Zone Android App

This is an isolated Android WebView app project for Property Zone.

- Website: https://prologisincpld.com/
- Package: com.propertyzone.app
- Minimum Android: 6.0 (API 23)
- Build: `gradle assembleDebug`

The app source is maintained on the `android-app-development` branch so the live website's `main` branch and deployed files are not changed.

The first build is a debug APK for device testing. A signed release APK/AAB and Google Play publishing setup are separate later steps.
